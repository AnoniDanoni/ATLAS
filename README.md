# ATLAS

O ATLAS (Atualization Library Automatic) é um verificador de arquivos desatualizados e novos, onde verifica a pasta selecionada e indica se a entrada (arquivos Revit ou DWG)
está mais recente do que a saída (arquivos IFC ou NWC).

A verificação é importante para a atualização de projetos, onde são sempre anexados novos arquivos ao modelo 3D, podendo ser tanto algum arquivo corrigido ou ajustado,
quanto um arquivo novo.

Após realizar a verificação da pasta, o ATLAS te dá um relatório dos arquivos que estão desatualizados ou novos, juntamente com o caminho clicável, para facilitar o processo
de ida até a pasta desejada.
